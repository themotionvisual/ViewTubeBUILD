# Toolbox UI Library v2 acceptance

- [ ] Studio Hub UI Library outer shell renders as a Main Toolbox, not a Subtoolbox.
- [ ] Main header is visually larger/heavier than every nested Subtoolbox header.
- [ ] Standard nested Subtoolbox uses 56px/4px/12px/6px/20px contract.
- [ ] Compact nested Subtoolbox uses 44px/3px/10px/4px contract.
- [ ] Split-left controls keep square icon rails at every responsive width.
- [ ] Dropdown closed/open states retain ViewTube stroke, radius, typography, palette and colored shadow language.
- [ ] Palette selector exposes all 12 ViewTube spectrum colors.
- [ ] Tag examples use compact uppercase spectrum badges and matching shadows.
- [ ] Inputs, textareas, selects, buttons, metrics, outputs, upload target and state panels use canonical primitives.
- [ ] Mobile layout stacks without horizontal overflow.
- [ ] No widget stylesheet is required to establish Toolbox/Subtoolbox geometry.
