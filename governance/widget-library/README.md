# Widget Library — standalone HTML reference

Published design references for the ViewTubeX widget system, exported from their
Claude artifacts as self-contained HTML (all CSS and JS inline; fonts load from
Google Fonts, with system fallbacks offline).

| File | Contents |
| --- | --- |
| `widget-library-v10.html` | Rounds 08–10: 10 upload-frame variants, 24 px icon system, circle/square glyph choices, spectrum split badges, asset-frame ladder, 5 widget layouts |
| `widget-library-v11-interactive-set.html` | The 10-ring oscillating upload frame plus the interactive-controls catalog: toggles, radios/checks, segmented, sliders, steppers, toasts, pagination, command palette, kanban, leaderboard, stat tiles, avatars |
| `widget-library-v12-matrix.html` | 4 colour systems × 4 heights × 19 components, with live hover/active/focus states |

Reference material only — nothing here is imported by the app. Open any file
directly in a browser.
