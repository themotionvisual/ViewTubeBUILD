01

Ten-ring oscillating upload frame

Hover to trigger

Solid box at --widget-color 20 %. Ten concentric outlines, 10 px each. Hover jumps everything to 40 %, then the two ring groups (odd / even) breathe apart to 60 / 20, back to uniform, then the opposite way to 20 / 60, and back — a slow 6-second wave that keeps running while the mouse is over. Uses CSS @property so the opacity percentages interpolate smoothly through the keyframes.
