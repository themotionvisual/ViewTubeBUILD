## Precedence rules

Use the following precedence unless a living resource explicitly changes it:

1. Current runtime code + passing focused tests.
2. Current living master resource for the bounded concern.
3. Current registries, schemas, and generated inventories.
4. Current implementation plans with explicit status and owners.
5. Historical plans, donor branches, standalone HTML, screenshots, and prior audits.

If the sources disagree, report the conflict and classify it. Do not silently reconcile it.
