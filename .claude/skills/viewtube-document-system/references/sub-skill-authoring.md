# Sub-skill authoring

Sub-skills make a repeated procedure executable. They do not become architecture authority.

## Create a sub-skill only when

- the procedure recurs across multiple tasks/conversations;
- mistakes are costly or common;
- the procedure has stable inputs/outputs;
- specialized verification is needed;
- a domain benefits from just-in-time instructions smaller than the main skill.

Otherwise update the existing parent skill/reference.

## Required structure

Front matter:
- name
- narrow description/trigger

Body:
1. purpose;
2. governing authorities;
3. mandatory reads;
4. inputs/assumptions;
5. ordered procedure;
6. anti-duplication/owner rules;
7. verification;
8. outputs/receipt;
9. escalation/stop conditions;
10. references.

## Inheritance

Every sub-skill created by viewtube-document-system inherits:
- Documentation Governance;
- Product Completion Constitution;
- Product Architecture;
- Verification;
- Task Authority boundaries;
- current repo workflow.

Do not restate these at length; cite them.

## Naming

Use functional names such as:
- viewtube-document-consolidation
- viewtube-domain-authority-audit
- viewtube-html-family-consolidator
- viewtube-doc-registry-validator

Avoid titles that imply new product/system authority.

## Sub-skill creation workflow

RECONCILE existing skills
→ DEFINE repeated job
→ CONFIRM parent authority
→ AUTHOR narrow skill
→ ADD references/templates only when reusable
→ TEST on a real or representative case
→ REGISTER in parent skill/reference map
→ RECORD receipt.

## Capabilities

A sub-skill may:
- update/create governed documents;
- recommend plans/audits/reports/decisions;
- propose capability/task changes;
- author/update other subordinate sub-skills when explicitly within its remit;
- generate standalone HTML/reference artifacts;
- create verification/check tooling.

It may not:
- directly redefine product truth outside owning authorities;
- allocate competing task/status ledgers;
- treat a prototype as production;
- mark implementation DONE without Task Authority/evidence.
