# Consolidation and Removed Archive

## Family discovery

Group versions by shared purpose, not only filename. Include renamed versions, branch donors, Library artifacts, HTML prototypes, exported copies and historical plans.

## Lossless accounting dimensions

Compare:
- headings/prose/tables;
- code blocks;
- HTML structure;
- CSS/tokens/responsive rules;
- JavaScript/interactions;
- embedded JSON/data/config;
- comments/hidden agent instructions;
- task IDs/status claims;
- decisions/rules;
- URLs/PR/branch/path references;
- images/media/resource pointers;
- persistence/import/export behavior;
- mobile/desktop behavior;
- accessibility/keyboard/touch behavior.

## Disposition per unique contribution

INCORPORATED
TASK_INDEX
DECISION_RECORD
REFERENCE
ARCHIVED_ONLY
SUPERSEDED
CONFLICT_REQUIRES_DECISION

Never discard an unaccounted unique contribution.

## Archive procedure

1. establish target survivor;
2. create manifest using docs/governance/consolidation-manifest.schema.json;
3. verify hashes and inbound references;
4. harvest current durable content;
5. route unfinished work;
6. preserve original source under archive/removed/;
7. update archive index;
8. update registry/supersession;
9. verify no active source still treats archived material as authority.
