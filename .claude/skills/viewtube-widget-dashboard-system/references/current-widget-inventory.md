## Inventory rules

- Treat the registry ID as persistent user data.
- Preserve IDs through redesigns; use migrations/aliases for intentional renames.
- A renderer file may implement more than one registry ID.
- Some older widgets are still inline in `WidgetRendererBase.tsx`; extract them incrementally rather than restoring whole historical files.
- `newWidgetSet.ts` source definitions still carry prototype language, while `WidgetRegistry.ts` promotes them into the preview registered set. Verify runtime metadata before describing release status.
- A `ready` registry flag is not certification. Use the certification gates in this skill.
- For exact behavior always inspect the current TSX plus its data adapters/actions; this table is a navigation and management inventory, not a substitute for code review.
