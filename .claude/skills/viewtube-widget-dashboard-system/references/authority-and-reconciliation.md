# Authority and reconciliation

Canonical chain: TOKENS -> PRIMITIVES -> UI REFERENCE LIBRARY -> ARCHETYPES -> COMPOUND COMPONENTS -> WIDGETS -> SHELL -> DASHBOARD LAYOUT.

Reconcile older skills, .claude/.codex copies, architecture docs, reference HTML, CSS, tests, and current production code. Classify each inherited rule KEEP, UPDATE, MERGE, SUPERSEDE, CONTRADICTION, or OBSOLETE. Newer measured/certified authority and current production behavior outrank stale prose. Record contradictions explicitly.

Known reconciliation: older widget guidance saying black icon strokes conflicts with the newer certification/color contract. Use current ViewTube Ink/palette ownership and do not perpetuate black widget strokes/text.

Never delete an old skill until all consumers, links, registries, references, unique rules, and useful examples have migrated.
