## Editing rule

Before changing any widget:

1. locate registry metadata;
2. locate actual renderer;
3. locate widget-specific CSS;
4. locate primitive consumers;
5. locate data/action adapters;
6. search tests;
7. search historical/prototype references only after current ownership is understood.
