# Idea Source Lists

Store original idea lists here by broad source category.

Recommended folders:
- `governance/`
- `product/`
- `ui-ux/`
- `ai/`
- `analytics/`
- `editor-video/`
- `workflows/`
- `infrastructure/`

Lists may be messy and overlapping. Do not manually delete duplicates from source lists.

Deduplication happens in `ideas/registry.json`, preserving every source reference.
