# HERALD-ARTIFACTS — saving and organising what a conversation produces

Every conversation that produces a document, artifact, standalone HTML file or screenshot
saves it here, organised, before the turn ends. An artifact that exists only in chat
scrollback does not exist.

## Location

```
docs/herald/artifacts/<YYYY-MM-DD>--<conversation-slug>/
├── README.md            what this conversation produced — the index
├── SCREENSHOTS.md       every screenshot inline, chronological, scrollable in one view
├── screenshots/         the image files + optional manifest.json
├── documents/           single-version documents, loose
└── <family-slug>/       a versioned family (see below)
```

One folder per conversation. The slug is short and descriptive: `2026-09-16--herald-system`,
not `2026-09-16--session`.

`docs/herald/**` is git-allow-listed, so everything here tracks normally and renders on
GitHub. Nothing in this tree needs `git add -f`.

## Versioned families — the folder rule

A **single** version stays a loose file in `documents/`. The moment a **second** version of
the same thing exists, promote it to a family folder:

```
<family-slug>/
├── <family-slug>.html                    ← THE CHOSEN ONE, loose in the folder
├── VERSIONS.md                           ← why this one, and what each variant was
└── variants/
    ├── <family-slug>--2026-09-10--v1.html
    ├── <family-slug>--2026-09-14--wider-header.html
    └── <family-slug>--2026-09-16--v3.html
```

**The canonical version sits loose in the family folder. Every other variant sits inside
`variants/`.** Open the folder, and the file you see is the one to use.

### Choosing the canonical version — in this order

1. **Explicitly decided best** — the creator said so. Record the reason in `VERSIONS.md`.
   This beats everything below.
2. **Most recent** — by content date, not file mtime, which copying destroys.
3. **Largest** — the tie-break when two are same-day and no decision was recorded.

Never delete a variant to tidy up. Superseded is not worthless: a variant often records why
an approach was abandoned, which is the single most expensive thing to rediscover.

### VERSIONS.md

```markdown
# <family-slug>

**Canonical:** `<family-slug>.html` — chosen 2026-09-16 because <one line>.
**Selected by:** explicit decision | most recent | largest

| Variant | Date | Size | What it was | Why not canonical |
|---|---|---|---|---|
| `variants/…--v1.html` | 2026-09-10 | 48 KB | first pass | superseded |
```

## Screenshots — one scrollable document

Every screenshot goes in `screenshots/`, and **`SCREENSHOTS.md` embeds all of them inline
in chronological order** so the whole set can be scrolled in one view, locally or on GitHub.

Each entry carries the same metadata the §10 VISUAL block requires:

```markdown
## 3. Dashboard after the height-bucket fix
`/dashboard` · 390×844 · `claude/fix-widget@a1b2c3d` · live · authenticated

![Dashboard after the height-bucket fix](./screenshots/03-dashboard-mobile.png)
```

Filenames are ordered: `NN-<slug>-<viewport>.png`. `SCREENSHOTS.md` is **generated** — run
`node scripts/herald-artifacts.mjs index <folder>` rather than editing it by hand. It reads
`screenshots/manifest.json` when present, which is the format
`scripts/capture-phase5-built-ui.mjs` already writes.

## README.md — the conversation index

Generated by the same command. Lists every document, family and screenshot with its one-line
purpose, so the folder is legible without opening anything.

## Rules

1. **Save before the turn ends.** Not "at the end of the project".
2. **Never leave an artifact only in chat.** If you produced it, it lands here.
3. **Never hand-edit `SCREENSHOTS.md` or `README.md`** — regenerate them.
4. **Second version triggers a family folder.** Do not accumulate `foo.html`, `foo2.html`,
   `foo copy.html` beside each other.
5. **Never delete a variant.** Move it to `variants/`.
6. **Record the canonical choice and its reason** in `VERSIONS.md`.
7. **Cross-reference, do not duplicate.** A document that belongs in `docs/` lives in
   `docs/` and is *linked* from the conversation README.
8. **No secrets.** Screenshots of authenticated views must not show tokens, keys or
   personal data; crop or redact first.

## Commands

```bash
node scripts/herald-artifacts.mjs init <slug>            # create the conversation folder
node scripts/herald-artifacts.mjs promote <family> <file> # make <file> canonical
node scripts/herald-artifacts.mjs index [<folder>]        # regenerate README + SCREENSHOTS
node scripts/herald-artifacts.mjs check                   # validate the convention
```

`check` runs in CI and fails when a family has no canonical file loose, when variants sit
outside `variants/`, or when a generated index is stale.
