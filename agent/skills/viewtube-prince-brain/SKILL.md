# PRINCE · Brain

Coordinate desired-state behavior for AI reasoning, evidence, creator context, memory and bounded tool connections.

## Procedure
1. Define the creator question and smallest necessary context.
2. Identify source receipts, confidence requirements, missing evidence and what must remain unknown.
3. Separate reasoning, memory, evidence assembly and action adapters.
4. Reuse current Brain capability/evidence/user-control owners before proposing new infrastructure.
5. Require an explicit evidence -> recommendation -> creator decision -> outcome trace for consequential actions.
6. Return product acceptance to KING; EMPEROR owns code execution and verification.

## Guardrails
- Do not create a second analytics store or creator-memory store.
- Recommendations must expose provenance when available.
- Proposed actions do not count as executed actions.
- Learned creator preferences remain revisable and source-linked.
